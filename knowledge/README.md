# octo-cli 知识库

本目录用于 AINOL Agent 实操考核，覆盖 octo-cli 的九大知识块。所有关键结论必须给出可核验引用：

```text
来源: <相对 octo-cli 仓库路径>#L<起>-L<止>
```

回答规则：

1. 有证据才给确定结论。
2. 没证据就说“不确定”，并说明需要补哪块源码证据。
3. 不编造路径，不编造行号。
4. 回答前应跑 `scripts/verify_citations.py` 或确认引用已通过校验。

九大知识块：

1. 凭证与权限
2. 配置与环境变量
3. 传输与重试
4. 输出与错误
5. 通用参数
6. 功能域与操作
7. 安装与发布
8. 安全与本地存储
9. Agent Skills
